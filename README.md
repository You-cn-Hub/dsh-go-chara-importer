# dsh-go 角色卡导入插件（local-chara）

在 dsh-go 手机 App 里用的本地插件：把 SillyTavern 角色卡（chara_card_v2 JSON）放进手机目录，点一下就能开演。

## 功能

- 输入框上方出现胶囊 **「角色卡」**，点开面板，列出手机目录里所有角色卡。
- 点一张卡 = 一次完成两件事：
  1. **开场白放进输入框**（不自动发送，可先改再发）；
  2. **清洗后的完整设定复制到剪贴板**（剥掉 HTML 标签，截取前 8000 字；含简介、设定、性格、输出规则、世界书）。
- 新对话里先粘贴设定发送，再发开场，角色卡即可直接使用。
- 换卡不用重装插件：往卡片目录里放新 JSON 就行，面板每次打开自动重新扫描。

## 卡片放哪里

```
/sdcard/Download/DSH-Go/cards/     （安卓手机，推荐）
$DSH_HOME/dsh-go/cards/            （引擎侧，兜底）
```

把 `*.json` 角色卡放进任一目录即可；也可以直接把卡文件发给助手帮你放。

## 安装

在 dsh-go 本机引擎（或装了 dsh-go 桥接的主机）上：

```sh
dsh plugin --profile web add <本插件目录>
```

安装后**重启一次引擎**（App「引擎」页），胶囊和面板才会出现。

## 卸载

```sh
dsh plugin --profile web remove local-chara
```

然后删掉插件目录。

## 说明

- 插件只读卡片目录、生成文本；不联网、不上传任何数据。
- 角色卡文件留在手机本地，不会打进这个仓库。
- 角色卡若有「破限 / 越狱」指令，插件不会执行它们，只作设定文本处理。
